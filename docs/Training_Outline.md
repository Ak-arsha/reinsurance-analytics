# Training outline (45 minutes), delivered separately to underwriters and actuaries

1. **Why this exists** (5 min): one source of truth; what changed vs old spreadsheets.
2. **Tour** (15 min): Overview, Risk, Line of business, Claims, Data quality. Live exercise: find the weakest line in North America.
3. **Definitions that cause arguments** (10 min): written vs earned, paid vs incurred, underwriting year vs loss date, why open claims matter. (Actuaries: no IBNR, FX basis.)
4. **Trusting the numbers** (5 min): Data quality page, what 'quarantined' means, what to do if a figure looks wrong.
5. **Getting more** (5 min): the Excel pack, CSV extracts, how to request data (see User Guide).
6. **Questions / feedback form** (5 min). Capture requests into the enhancement backlog.

## Enhancement backlog
1. IBNR / ultimate loss estimate by underwriting year (chain-ladder on a proper paid/incurred history).
2. Historic FX rates by transaction date.
3. Treaty renewal comparison (rate change, loss-ratio change).
4. Accumulation view by peak zone and return period.
5. Snapshot history of each load so figures can be compared month to month.
6. Qlik Sense version of the Overview page.
