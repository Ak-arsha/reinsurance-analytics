2. Architecture & Data Governance Flow

End-to-End Pipeline from Source Ingestion to Executive Dashboards

1. Ingestion & Staging
  • System A (Treaties), System B (Claims), System C (Premium/Exposure).
  • Staged into raw tables without silent data loss.
  • Unmapped values flagged in v_unmapped_values.
2. 28 Data Quality Checks
  • Reconciliation rule: Source = Core + Quarantined.
  • Quarantined rows routed to dq_failed_records.
  • Clean data loaded to dim_treaty, fact_premium, fact_claims.
3. MI Views & Reports
  • v_treaty_summary view locks loss & combined ratio logic.

  • Power BI Project (.pbip) & Qlik (.qvs) load scripts.

4. Power BI Project (.pbip) & DAX Measures

Enterprise Business Intelligence Model Architecture

Star Schema Model
  • Conformed dim_treaty dimension connecting cedants, regions, LOBs.
  • Fact tables (fact_premium, fact_claims, fact_exposure).
  • dim_date table marked as Date Table for time intelligence.
Key DAX Measures
  • Gross Written Premium: SUM(fact_premium[gross_written_premium])
  • Loss Ratio: DIVIDE([Incurred Losses], [Earned Premium])
  • Combined Ratio: [Loss Ratio] + [Commission Ratio] + 0.05
  • Limit Utilisation: DIVIDE([Incurred Losses], SUM(dim_treaty[limit_usd]))

7. Data Governance & Mapping Procedure

Adding New Regions, LOBs, and Currencies
