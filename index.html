Platform Highlights & Architecture

Built specifically to simulate the work of the AXA XL Reinsurance Portfolio Analytics team in Gurgaon, Haryana, India. Ingests synthetic data from 3 source systems (700 treaties, ~8,000 premium transactions, ~6,000 claims) into a star-schema warehouse with a governed SQL MI view layer.

Key Platform Features

  • Single Version of the Truth: Metric definitions (Loss Ratio 68.8%, Combined Ratio, Limit Utilisation) locked in SQL MI views (v_treaty_summary).
  • Automated Reconciliation: Proves Source Premium ($1,292.9M) = Core Loaded ($1,289.5M) + Quarantined ($3.4M) with zero silent data loss.
  • VBA Macro Suite: Automated pre-release audit (ValidatePack) and regional pack generation (SplitByRegion).
  • Governed Mapping Framework: Ownership of mapping tables (map_region, map_lob) via automated script (add_mapping.py).
